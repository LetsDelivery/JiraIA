## Onde o importador roda

Um comando, `bun run import:atlassian -- <passo> [--only TEC,REQ] [--previous <run>]`, numa máquina
com o perfil da AWS da conta (`lets-dev` por padrão), falando com o banco pelo Data API como a API
faz. Lê os tokens do segredo `jiraia/atlassian` e recusa rodar com token vencido. Não é Lambda: a primeira
carga passa dos 15 minutos de uma Lambda (3.230 cards só no TEC, 435 MB de anexos). Cada passo é
idempotente (`import_refs`) e pode ser interrompido e retomado.

O código fica em `services/work/src/import/`, com `AtlassianSource` (o tipo do importador sobre as
APIs) e `InMemoryAtlassian` nos testes; as APIs reais respondem em `.counterparty.test` pelo MSW.
