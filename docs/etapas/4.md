# Etapa 4 — LET’S Draw AI (páginas)

## Entrega

| Item do escopo | O que existe |
|---|---|
| Produto à parte | **LET’S Draw AI** é o “Confluence” do JiraIA (ADR-0010): o botão na barra lateral do JiraIA abre `/draw` em outra aba, com marca e barra lateral próprias, e o **JiraIA ↗** leva de volta |
| Espaços próprios | Os espaços do Draw não são os do JiraIA (ADR-0011): qualquer pessoa cria um (**Criar espaço**: nome, ícone, descrição), toda a organização lê; quem edita e administra veio depois, em `4b.md`; quem criou, ou um admin da organização, muda e exclui em **Configurações do espaço**. Estrela e **Seguir** são de cada pessoa |
| Barra lateral do espaço | No formato do Confluence: o espaço com o menu **⋯** (estrela, seguir, ferramentas do espaço → configurações), **Conteúdo** com **+** e filtro por tipo, **Pesquisar por título**, a árvore e **+ Criar** |
| 5.1 Árvore | Pastas, subpastas, páginas e quadros; **+** em cada item cria dentro dele; arrastar reordena ou aninha (topo da linha antes, base depois, meio dentro); dobrar; excluir (só vazio) |
| Criar | **Criar com IA** (o principal), **Página em branco**, **Quadro branco** e **Pasta** — no **+** do Conteúdo, no **+** de cada item, em **+ Criar** e nas telas do espaço e da pasta |
| Criar com IA | Modal com chat: a pessoa descreve (ou escolhe uma sugestão), indica **Automático / Página / Quadro branco**, a IA devolve um rascunho com prévia, dá para pedir ajustes no mesmo chat e **Criar página / Criar quadro**. Claude Opus 5.5 com saída estruturada e fallback do lado do servidor; sem a chave (pendência #8), o ambiente local monta um esboço e avisa que não é IA |
| Quadro branco | Notas, retângulos, elipses, texto, molduras, setas e caneta; mover, redimensionar pelo canto, duplo clique para escrever, cores, zoom (Ctrl + roda), Delete; coeditado em tempo real, com o cursor e o nome de cada pessoa |
| 5.2 Editor rico | TipTap: títulos, listas, tarefas, citação, destaque, realce, código, tabela, imagem, anexo, divisor, comando **/** e atalhos markdown |
| 5.3 Coedição | Yjs sobre API Gateway WebSocket + Lambda (ADR-0009), para páginas e quadros |
| 5.4 Versões | Automáticas e **Salvar versão agora**; comparar com o atual e restaurar (chega a quem está editando) — páginas e quadros |
| 5.5, 5.6 | `@` pessoas e agentes, `#` cards, **/Card** embutido com estado atual; **Criar card** a partir do trecho |
| 5.7 Comentários | No conteúdo ou num trecho (páginas); fios, resolver |
| Busca | `/busca` acha páginas e quadros pelo título e pelo texto |

API: `/draw/spaces` (+ `marks`, `drafts`), `/draw/spaces/{id}/contents`, `/draw/contents/{id}` (+ `move`,
`document`, `derived`, `versions`, `comments`, `files`, `realtime`), `GET /draw/contents` (recentes).

No seed, o espaço **🧭 Produto** tem a estrutura do Confluence de Produto: `01. Antigo`, `02. Novo` →
`01. Processos` (com **Esteira de produto** e **Requisições para Produto**), `02. Discovery`,
`03. Delivery`, `04. Meetings`.

## Demonstração

`bun run up`, e em duas janelas (uma anônima), `admin@uselets.com` e `ana@uselets.com`:

1. Na barra lateral do JiraIA, **LET’S Draw AI** → **Produto** → `02. Novo` → `01. Processos` →
   **Esteira de produto**: as duas pessoas digitam ao mesmo tempo.
2. **+** ao lado de **Conteúdo** → **Criar com IA** → “Mapeie a jornada do lojista no app” → **Criar quadro**;
   a outra janela abre o quadro e vê as notas mexerem.
3. **Versões** → **Salvar versão agora**, mudar, abrir a versão, **Restaurar**.

`bun run web:e2e` percorre o mesmo caminho (`playwright/e2e/draw.spec.ts`).

**Pronto quando** (do prompt de construção): duas pessoas editam a mesma página ao mesmo tempo sem
perda, e uma versão antiga é restaurada — `draw.spec.ts` e `draw.integration.test.ts`.
